## 🚀 PipeFlow — B2B 배관 견적·발주 서비스

건설·설비 현장에서 배관 자재를 산출(BOM)하고 견적·발주까지 이어지는 과정을
하나의 서비스로 묶었습니다. **현재 실제 사용자가 있는 운영 서비스**이며, 기능을 계속 확장하고 있습니다.

### 제가 직접 설계하고 구현한 것들

| 영역 | 무엇을 / 왜 |
|---|---|
| **결제 연동** | Toss Payments 가상계좌 연동. 입금 통지(Webhook) 처리와 멱등성 보장, 결제 상태 전이 설계 |
| **사업자 검증** | 국세청 공공데이터 API 연동으로 사업자등록번호 진위 확인 — B2B 서비스의 신뢰 기반 |
| **단일 세션 정책** | 계정 동시 로그인 차단. 세션 상태 관리와 동시성 처리를 어디에 둘지에 대한 설계 결정 |
| **BOM 산출 / 3D 측정** | 도면 기반 자재 산출 로직과 3D 측정 모드 |
| **스키마 관리** | Alembic 기반 마이그레이션 운영 — 운영 중인 DB를 안전하게 바꾸는 방법 |
